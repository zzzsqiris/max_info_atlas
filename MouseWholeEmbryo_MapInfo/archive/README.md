# Historical experiments

This directory contains local and Hoffman2 snapshots of three superseded
spatial workflows:

- `starmap/`: rejected because the spatial dataset was too small.
- `merfish_ec_only/`: rejected because the EC-only target introduced
  structural gaps.
- `merfish_whole_embryo/`: rejected because the MERFISH gene panel was biased
  toward endothelial-cell genes.

The full snapshots are intentionally excluded from GitHub. They remain local
and on Hoffman2 for provenance and recovery. The active workflow uses the
whole-embryo snRNA reference with Visium HD and Stereo-seq under `../datasets/`.
